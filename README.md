# Speaking Practice (WIDA ACCESS style)

Practice for the WIDA ACCESS Speaking test, in the style of the online test. This is not an official WIDA product.

- `teacher.html`: choose tasks and settings, then copy a student link.
- `index.html`: the student practice. It opens the tasks that are in the link.
- `tasks.js`: the task bank (30 WIDA 1–2 tasks and 30 WIDA 3–4 tasks).
- `pics.js`, `app.css`: pictures and styles.
- `audio/`: the recorded voices for every task.

Student recordings and transcripts are never uploaded anywhere by this site. They stay in the student's browser until the student saves them and uploads them to Canvas.

## Put it on GitHub Pages (free)

1. Make a free account at github.com.
2. Click **+** (top right) → **New repository**. Name it `speaking-practice`. Choose **Public**. Click **Create repository**.
3. On the new repository page, click **uploading an existing file**.
4. Unzip the download on your computer. Open the `speaking-practice` folder, select **everything inside it** (including the `audio` folder), and drag it onto the GitHub page. Wait until all files finish uploading, then click **Commit changes**.
5. Go to **Settings** → **Pages**. Under **Branch**, choose **main** and **/(root)**, then click **Save**.
6. Wait 1–2 minutes and refresh. GitHub shows your site address, like `https://YOURNAME.github.io/speaking-practice/`.
7. Your teacher page is that address plus `teacher.html`, for example `https://YOURNAME.github.io/speaking-practice/teacher.html`. Bookmark it.

## Make an assignment

1. Open your teacher page. Choose **WIDA 1–2** or **WIDA 3–4**, then click **+ Add** on up to 12 tasks.
2. Type an assignment name and choose the settings.
3. Click **Copy** and paste the link into a Canvas assignment. Set the Canvas assignment to accept file uploads.
4. Click **Open as a student** to try it yourself first.

Students open the link in Chrome, do the microphone check, answer the questions, and then save two files (a recording and a transcript) to upload to Canvas.

## Updating

If you get a new version of these files, upload them to the same repository the same way. GitHub replaces the old files, and your links keep working.
